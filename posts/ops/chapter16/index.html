介绍

Volta 是一种管理 JavaScript 命令行工具的方式，无缝的按项目版本切换，无需在每次 Node 升级时重新安装

1 安装

1.1 Unix 安装

使用如下命令安装

curl https://get.volta.sh | bash

修改环境变量

# /etc/profile

VOLTA_HOME=$HOME/.volta
export PATH=$PATH:$VOLTA_HOME/bin

应用环境变量

source /etc/profile

验证

volta --version

1.2 Windows 安装

通过 winget 安装

winget install Volta.Volta

1.3 通过二进制包安装

下载二进制包

wget https://github.com/volta-cli/volta/releases/download/v2.0.2/volta-2.0.2-linux.tar.gz

解压并添加到合适的路径

tar -zxvf volta-2.0.2-linux.tar.gz
mv volta-2.0.2-linux /usr/local/bin

验证

volta --version

2 使用

2.1 获取已安装的工具

volta list

2.2 安装工具

volta install node@22.12.0    # volta install pnpm@9.14

2.3 项目中指定工具版本

volta pin node@22.12.0

2.4 卸载工具

volta uninstall <tool>    # `node`, `npm`, `yarn`, or <package>

3 其他

3.1 环境变量配置

全局安装路径

npm config set prefix <global_path>

缓存路径

npm config set cache <cache_path>

3.2 问题与修复

  1. Error: spawn xdg-open ENOENT

安装 xdg

yum install xdg-utils
