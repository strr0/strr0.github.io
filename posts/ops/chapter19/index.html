1 概念

1.1 基本定义

Hadoop 是一个开源的分布式计算平台，允许用户在不了解分布式底层细节的情况下，开发分布式程序，充分利用集群的威力进行高速运算和存储。它主要解决两大问题：‌海量数据存储‌（通过 HDFS）和‌海量数据分析‌（通过 MapReduce）。

1.2 核心组件

1.2.1 HDFS(Hadoop Distributed File System)

分布式文件系统，将数据分割为块（默认 128 MB）并存储在不同服务器上，支持高吞吐量访问和容错。

  • NameNode‌：管理文件命名空间和元数据。

  • DataNode‌：存储实际数据块并执行读写操作。

1.2.2 MapReduce

分布式计算模型，分为 Map（映射）和 Reduce（归约）两阶段，适用于离线批处理。

1.2.3 YARN(Yet Another Resource Negotiator)

资源调度框架，分离资源管理与任务调度，支持多类型计算框架（如 Spark、Flink）。

2 安装

2.1 环境要求

  • jdk8
  • ssh

2.2 安装

下载 hadoop-3.4.1.tar.gz

解压

mkdir /opt/apache
sudo tar -zxvf hadoop-3.4.1.tar.gz -C /opt/apache

2.3 配置

配置环境变量

# /etc/profile

# set to the root of your Java installation
export JAVA_HOME=/usr/java/latest

刷新环境变量

source /etc/profile

2.4 验证

执行如下命令验证，成功则打印使用说明

bin/hadoop

3 使用

3.1 单机模式

  1. 复制配置文件作为输入
mkdir input
cp etc/hadoop/*.xml input
  1. 查找和打印所有表达式匹配的数据
bin/hadoop jar share/hadoop/mapreduce/hadoop-mapreduce-examples-3.4.1.jar grep input output 'dfs[a-z.]+'
cat output/*

3.2 伪分布式

3.2.1 配置

  1. 使用如下配置

etc/hadoop/core-site.xml

<configuration>
    <property>
        <name>fs.defaultFS</name>
        <value>hdfs://localhost:9000</value>
    </property>
</configuration>

etc/hadoop/hdfs-site.xml

<configuration>
    <property>
        <name>dfs.replication</name>
        <value>1</value>
    </property>
</configuration>

3.2.2 设置 SSH

  1. 检查是否可以免密登录
ssh localhost

如果不能免密登录，执行如下命令

ssh-keygen -t rsa -P '' -f ~/.ssh/id_rsa
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 0600 ~/.ssh/authorized_keys

3.2.3 执行

  1. 格式化文件系统
bin/hdfs namenode -format
  1. 启动 NameNode 和 DataNode
sbin/start-dfs.sh

hadoop 的日志会输出到 $HADOOP_LOG_DIR 目录下

  1. NameNode 默认 web 界面在 http://localhost:9870

  2. 创建执行 MapReduce 作业所需的 HDFS 目录

bin/hdfs dfs -mkdir -p /user/<username>
  1. 复制输入文件
bin/hdfs dfs -mkdir input
bin/hdfs dfs -put etc/hadoop/*.xml input
  1. 执行 example 作业
bin/hadoop jar share/hadoop/mapreduce/hadoop-mapreduce-examples-3.4.1.jar grep input output 'dfs[a-z.]+'
  1. 检查输出文件

复制分布式文件系统的输出文件到本地检查

bin/hdfs dfs -get output output
cat output/*

或直接通过分布式文件系统检查

bin/hdfs dfs -cat output/*
  1. 完成所有作业后，可以通过如下命令停止
sbin/stop-dfs.sh

3.2.4 通过 yarn 执行

此步需要已经完成上述的前 4 步操作

  1. 配置参数如下

etc/hadoop/mapred-site.xml

<configuration>
    <property>
        <name>mapreduce.framework.name</name>
        <value>yarn</value>
    </property>
    <property>
        <name>mapreduce.application.classpath</name>
        <value>$HADOOP_MAPRED_HOME/share/hadoop/mapreduce/*:$HADOOP_MAPRED_HOME/share/hadoop/mapreduce/lib/*</value>
    </property>
</configuration>

etc/hadoop/yarn-site.xml

<configuration>
    <property>
        <name>yarn.nodemanager.aux-services</name>
        <value>mapreduce_shuffle</value>
    </property>
    <property>
        <name>yarn.nodemanager.env-whitelist</name>
        <value>JAVA_HOME,HADOOP_COMMON_HOME,HADOOP_HDFS_HOME,HADOOP_CONF_DIR,CLASSPATH_PREPEND_DISTCACHE,HADOOP_YARN_HOME,HADOOP_HOME,PATH,LANG,TZ,HADOOP_MAPRED_HOME</value>
    </property>
</configuration>
  1. 启动 ResourceManager 和 NodeManager
sbin/start-yarn.sh

  1. ResourceManager 默认 web 界面在 http://localhost:8088

  2. 执行 MapReduce 作业

  3. 完成所有作业后，可以通过如下命令停止

sbin/stop-yarn.sh

3.3 分布式

搭建 Hadoop 集群需要准备至少 2 台以上的服务器，这边我使用 docker 来模拟 3 台服务器，节点规划如下

hadoop1 hadoop2 hadoop3
HDFS NameNode DataNode DataNode DataNode
Yarn NodeManager NodeManager ResourceManager NodeManager

3.3.1 Hadoop 集群搭建

  1. 创建容器
docker run -itd --name ubuntu ubuntu:24.04 /bin/bash

docker exec -it ubuntu /bin/bash

/etc/profile

apt install vim openssh-server
  1. Hadoop 配置

配置主节点信息

etc/hadoop/core-site.xml

<configuration>
    <!-- NameNode Uri -->
    <property>
        <name>fs.defaultFS</name>
        <value>hdfs://hadoop1:9000</value>
    </property>
</configuration>

DataNode 配置

mkdir /opt/apache/hadoop-3.4.1/data

etc/hadoop/hdfs-site.xml

<configuration>
    <property>
        <name>dfs.datanode.data.dir</name>
        <value>/opt/apache/hadoop-3.4.1/data</value>
    </property>
</configuration>

NodeManager 配置

etc/hadoop/yarn-site.xml

<configuration>
    <property>
        <name>yarn.acl.enable</name>
        <value>false</value>
    </property>
    <property>
        <name>yarn.nodemanager.aux-services</name>
        <value>mapreduce_shuffle</value>
    </property>
    <property>
        <name>yarn.resourcemanager.hostname</name>
        <value>hadoop3</value>
    </property>
</configuration>

任务调度配置

etc/hadoop/mapred-site.xml

<configuration>

    </property>
    <property>
        <name>mapreduce.jobhistory.webapp.address</name>
        <value>hadoop2:19888</value>
    </property>
</configuration>

退出容器

保存镜像

docker commit ubuntu hadoop:1.0
  1. 创建集群及 ssh 配置

运行容器

docker run -itd --name hadoop1 --net dev hadoop:1.0 /bin/bash
docker run -itd --name hadoop2 --net dev hadoop:1.0 /bin/bash
docker run -itd --name hadoop3 --net dev hadoop:1.0 /bin/bash

进入容器

docker exec -it hadoop1 /bin/bash
docker exec -it hadoop2 /bin/bash
docker exec -it hadoop3 /bin/bash

如果是 root 用户，则修改配置

/etc/ssh/sshd_config

PermitRootLogin yes

启动 ssh

service ssh start

生产公私钥

ssh-keygen -t rsa

将公钥上传到其他的服务器，如 hadoop1 执行如下命令

ssh-copy-id hadoop2
ssh-copy-id hadoop3

hadoop2、hadoop3 同理

3.3.2 运行

  1. 启动

首次运行 HDFS 需要执行格式化 HDFS（hadoop1）

bin/hdfs namenode -format

启动 NameNode

bin/hdfs --daemon start namenode

启动 DataNode

bin/hdfs --daemon start datanode

启动 ResourceManager

bin/yarn --daemon start resourcemanager

启动 NodeManager

bin/yarn --daemon start nodemanager

启动 WebAppProxy server

bin/yarn --daemon start proxyserver

启动 MapReduce JobHistory Server

bin/mapred --daemon start historyserver
  1. 停止

停止 NameNode

bin/hdfs --daemon stop namenode

停止 DataNode

bin/hdfs --daemon stop datanode

停止 ResourceManager

bin/yarn --daemon stop resourcemanager

停止 NodeManager

bin/yarn --daemon stop nodemanager

停止 WebAppProxy server

bin/yarn stop proxyserver

停止 MapReduce JobHistory Server

bin/mapred --daemon stop historyserver

3.3.3 Hadoop 可选配置

  • etc/hadoop/core-site.xml
Parameter Value Notes
fs.defaultFS NameNode URI hdfs://host:port
io.file.buffer.size 131072 Size of read/write buffer used in SequenceFiles.
  • etc/hadoop/hdfs-site.xml

NameNode

Parameter Value Notes
dfs.namenode.name.dir Path on the local filesystem where the NameNode stores the namespace and transactions logs persistently. If this is a comma-delimited list of directories then the name table is replicated in all of the directories, for redundancy.
dfs.hosts / dfs.hosts.exclude List of permitted/excluded DataNodes. If necessary, use these files to control the list of allowable datanodes.
dfs.blocksize 268435456 HDFS blocksize of 256MB for large file-systems.
dfs.namenode.handler.count 100 More NameNode server threads to handle RPCs from large number of DataNodes.

DataNode

Parameter Value Notes
dfs.datanode.data.dir Comma separated list of paths on the local filesystem of a DataNode where it should store its blocks. If this is a comma-delimited list of directories, then data will be stored in all named directories, typically on different devices.
  • etc/hadoop/yarn-site.xml

ResourceManager and NodeManager

yarn.admin.acl Admin ACL ACL to set admins on the cluster. ACLs are of for comma-separated-usersspacecomma-separated-groups. Defaults to special value of * which means anyone. Special value of just space means no one has access.
yarn.log-aggregation-enable false Configuration to enable or disable log aggregation

Parameter Value Notes

History Server

Parameter Value Notes
yarn.log-aggregation.retain-seconds -1 How long to keep aggregation logs before deleting them. -1 disables. Be careful, set this too small and you will spam the name node.
yarn.log-aggregation.retain-check-interval-seconds -1 Time between checks for aggregated log retention. If set to 0 or a negative value then the value is computed as one-tenth of the aggregated log retention time. Be careful, set this too small and you will spam the name node.
