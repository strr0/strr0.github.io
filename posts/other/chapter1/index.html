介绍

wsl 是一个在 Windows 上能够运行原生 Linux 二进制可执行文件的兼容层，相比于传统虚拟机，它启动速度更快，而且与 windows 的交互更加丝滑，挂载 windows 文件夹操作简单。缺点就是，使用它需要开启 Hyper-V，而 Hyper-V 会与其他虚拟机环境冲突，所以在开启 Hyper-V 后，会导致 VMware、安卓虚拟机等不能使用，若要使用则需要关闭 Hyper-V。

1 环境配置

1.1 WSL 环境

Windows 10 版本 2004 及更高版本（内部版本 19041 及更高版本）或 Windows 11 使用自动安装，否则使用手动安装

1.1.1 自动安装

执行安装命令

wsl --install

1.1.2 手动安装

1.1.2.1 启用“适用于 Linux 的 Windows 子系统”可选功能
1.1.2.2 检查运行 WSL 2 的要求

若要更新到 WSL 2，需要运行 Windows 10
对于 x64 系统：版本 1903 或更高版本，内部版本为 18362 或更高版本。
对于 ARM64 系统：版本 2004 或更高版本，内部版本为 19041 或更高版本。
或 Windows 11。

1.1.2.3 启用“虚拟机平台”可选功能
1.1.2.4 下载 Linux 内核更新包

下载最新包：适用于 x64 计算机的 WSL2 Linux 内核更新包
运行上一步中下载的更新包。

1.1.2.5 将 WSL 2 设置为默认版本
wsl --set-default-version 2

2 使用

2.1 配置

屏蔽 Windows 环境变量

# /etc/wsl.conf

[interop]
enabled=false
appendWindowsPath=false

2.2 基础操作

查看 wsl 版本

wsl -l -v

设置 wsl 版本

wsl --set-version <distribution> 2

启动 wsl

wsl -d <distribution>

关闭 wsl

wsl --shutdown

导出 wsl

wsl --export <image> <image_path>

导入 wsl

wsl --import <image> <target_path> <image_path> --version 2

wsl 子系统安装列表

wslconfig /l

卸载子系统

wslconfig /u <distribution>

2.3 其他操作

2.3.1 导入任何 Linux 发行版（CentOS）

在 Docker 中运行 CentOS 容器

docker run -t --name wsl_export centos ls /

将容器导出 tar 文件

docker export wsl_export > centos.tar

清理容器

docker rm wsl_export

将 tar 文件导入

wsl --import CentOS <target_path> centos.tar

2.3.2 安装 MySQL

更新可用的包

sudo apt update

安装 MySQL

sudo apt install mysql-server

验证

mysql --version

启动安全脚本提示符

sudo mysql_secure_installation

登录 MySQL 并设置 root 密码

sudo mysql -uroot
> alter user 'root'@'localhost' identified with 'caching_sha2_password' by '<password>'

2.3.3 安装 PostgreSQL

更新可用的包

sudo apt update

安装 PostgreSQL

sudo apt install postgresql postgresql-contrib

验证

psql --version

设置管理员密码

sudo passwd postgres

2.3.4 安装 Redis

更新可用的包

sudo apt update

安装 Redis

sudo apt install redis-server

配置

# /etc/redis/redis.conf

## 允许远程访问
# bind 127.0.0.1 -::1
## 密码配置
requirepass password
