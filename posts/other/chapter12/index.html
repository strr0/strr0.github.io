介绍

刷机指南

1 前置准备

1.1 驱动安装

一加手机可以从 daxiaamu 下载驱动

adb 与 fastboot 找不到设备问题：1. 驱动未安装；2. 手动从 此电脑 > 管理 > 设备管理器 选择未识别的设备右键 更新驱动程序软件

1.2 开启 USB 调试

多次点击 关于手机 > 版本号 开启开发者模式

开启 系统 > 开发者选项 的 OEM 解锁 及 USB 调试

1.3 解除 BL 锁

手机连接电脑

进 fastboot 模式

adb reboot bootloader

解锁

fastboot flashing unlock

解除 BL 锁会删除数据并重启，重启后重新 开启 USB 调试

1.4 刷入 TWRP

1.4.1 有 Recovery 分区

adb reboot bootloader
fastboot flash recovery twrp-<version>.img

1.4.2 无 Recovery 分区

进入临时 TWRP

adb reboot bootloader
fastboot boot twrp-<version>.img

上传加固包到手机

adb push twrp-installer-<version>.zip /tmp

在 TWRP 中 Install > Install Image 选择加固包并刷入

在新版本 Android 中取消了 Recovery 分区，加入了 A/B 分区（系统更新或卡刷 rom 时会在另一个 inactive 的分区中执行，执行完成后切换到这个分区，如果执行失败则退回原来的分区，两个分区共享一套 userdata），而 Recovery 为 Boot 分区的一个部分，需要通过卡刷的方式刷入

2 刷入 Windows

2.1 设备支持情况

查看 设备支持情况 以决定是否继续刷入

2.2 下载所需文件

从 UUP Dump 下载 Arm 版 Windows 镜像

从 WOA 下载对应设备驱动

从 edk2-msm 下载对应设备 UEFI 镜像

下载 Android Platform Tools

下载分区工具 parted

2.3 备份

手机进入 TWRP 并连接电脑，备份调制解调器

adb shell
dd if=/dev/block/by-name/fsc of=/tmp/fsc
dd if=/dev/block/by-name/fsg of=/tmp/fsg
dd if=/dev/block/by-name/modemst1 of=/tmp/bootmodem_fs1
dd if=/dev/block/by-name/modemst2 of=/tmp/bootmodem_fs2

下载备份文件到电脑

adb pull /tmp/fsc
adb pull /tmp/fsg
adb pull /tmp/bootmodem_fs1
adb pull /tmp/bootmodem_fs2

骁龙 845 及骁龙 855 设备需要配置调制解调器才能使数据及短信正常工作

在 TWRP 中 Backup 选择 Data 分区备份

下载备份文件到电脑

adb pull /sdcard/TWRP/BACKUPS

中文乱码问题：中文字体存在 Data 分区中，需提前备份

备份 boot

adb pull /dev/block/by-name/boot_a boot.img

刷 root 权限需要

2.4 分区操作

在 TWRP 中 Mount 取消 Data 分区挂载

上传分区工具到手机

adb push parted /tmp

授权及分区

adb shell
cd /tmp
chmod +x parted
./parted /dev/block/sda

打印分区信息

print

压缩 userdata 分区

resizepart <num>  # 如 resizepart 17 （userdata 在第 17 个分区），然后输入压缩后的 End 地址

创建 esp 分区

mkpart esp fat32 <start> <end>  # 如 mkpart esp fat32 20GB 20.3GB
set <num> esp on  # 如 set 18 esp on （esp 在第 18 个分区）

创建 win 分区

mkpart win ntfs <start> <end>  # 如 mkpart win ntfs 20.3GB -0MB

退出

quit

退出 ADB Shell 后，在 TWRP 中 Wipe > Format Data 格式化分区

重启系统查看 Android 是否正常启动，正常启动后系统中文乱码，重启到 TWRP

上传备份 Data 分区到手机

adb push BACKUPS /sdcard/TWRP

在 TWRP 中 Restore 选择备份的 Data 分区还原

再重启系统查看乱码是否正常了

重启到 TWRP，执行格式化

adb shell mkfs.ntfs -f /dev/block/by-name/win -L WIN
adb shell mkfs.fat -F32 -s1 /dev/block/by-name/esp -n ESP

2.5 安装

重启到 fastboot，启动 UEFI

fastboot boot boot.img

选择 Simple Init > Mass Storage 进入大容量存储模式

进入 DISKPART

diskpart

分配盘符

lis dis                               # 获取磁盘信息
sel dis <num>                         # 如 sel dis 6 （手机磁盘为 6）
lis par                               # 获取分区信息
sel par <num>                         # 如 sel par 23 （esp 分区为 23）
format quick fs=fat32 label="System"  # 格式化
assign letter="S"                     # 分配盘符
sel par <num>                         # 如 sel par 24 （win 分区为 24）
format quick fs=ntfs label="Windows"  # 格式化
assign letter="W"                     # 分配盘符
exit

获取镜像 index

dism /get-imageinfo /ImageFile:path\to\install.wim

部署镜像

dism /apply-image /ImageFile:<path/to/install.wim> /index:1 /ApplyDir:W:\

添加引导

bcdboot W:\Windows /s S: /f UEFI

安装驱动

dism /Image:W: /Add-Driver /Driver:<path to the driver folder> /Recurse

启用测试模式及禁用自动修复

cd S:\EFI\Microsoft\Boot
bcdedit /store BCD /set "{default}" testsigning on
bcdedit /store BCD /set "{default}" nointegritychecks on
bcdedit /store BCD /set "{default}" recoveryenabled no

取消挂载

mountvol S: /d

2.6 启动

重启到 fastboot，启动 UEFI

成功进入 Windows 后，按 Shift + F10 调出命令行

oobe\bypassnro  # 设置离线安装 Win11

2.7 修复

重启到 TWRP，上传备份文件

adb push fsc /tmp
adb push fsg /tmp
adb push bootmodem_fs1 /tmp
adb push bootmodem_fs2 /tmp

恢复备份文件

dd if=/tmp/fsc of=/dev/block/by-name/fsc
dd if=/tmp/fsg of=/dev/block/by-name/fsg
dd if=/tmp/bootmodem_fs1 of=/dev/block/by-name/modemst1
dd if=/tmp/bootmodem_fs2 of=/dev/block/by-name/modemst2

3 刷入 PostmarketOS

3.1 下载所需文件

下载设备对应 image

3.2 分区操作

中文乱码问题见上述刷入 Windows 的 分区操作 处理

在 TWRP 中 Mount 取消 Data 分区挂载

上传分区工具到手机

adb push parted /tmp

授权及分区

adb shell
cd /tmp
chmod +x parted
./parted /dev/block/sda

打印分区信息

print

压缩 userdata 分区

resizepart <num>  # 如 resizepart 17 （userdata 在第 17 个分区），然后输入压缩后的 End 地址

创建 systempmos 分区

mkpart systempmos ext4 <start> <end>  # 如 mkpart systempmos ext4 90GB -0MB

退出

quit

退出 ADB Shell 后，在 TWRP 中 Wipe > Format Data 格式化分区

重启到 TWRP，执行格式化

adb shell mke2fs /dev/block/by-name/systempmos

3.3 刷入镜像

重启到 fastboot 刷入镜像

fastboot set_active b
fastboot erase dtbo_b
fastboot flash boot <pmos-boot.img>
fastboot flash systempmos <pmos.img>

3.4 Android 与 PostmarketOS 切换

3.4.1 Android 下

重启到 TWRP

在 TWRP 中 Reboot 选择 Slot B，重启则切换到 PostmarketOS

3.4.2 PostmarketOS 下

切换 Slot

sudo qbootctl -s a

重启则切换到 Android

5 刷入 PixelExperience

5.1 前置准备

5.1.1 升级系统

升级到 HydrogenOS 11 或 OxygenOS 11

5.1.2 分区固件同步

下载同步包 copy-partitions-20210323_1922.zip

重启到 TWRP，在 TWRP 中 Apply Update 选择 Apply from ADB，刷入同步包

adb sideload copy-partitions-20210323_1922.zip

5.1.3 初始化动态分区

重启到 fastboot

刷入 vbmeta

fastboot flash vbmeta_a vbmeta.img
fastboot flash vbmeta_b vbmeta.img

刷入 recovery

fastboot flash boot <recovery_filename>.img

擦除旧分区数据

fastboot erase system_a
fastboot erase system_b
fastboot erase odm_a
fastboot erase odm_b
fastboot erase vendor_a
fastboot erase vendor_b

重启到 recovery 再进入 fastboot

刷入 super_empty

# 当前为 a 分区
fastboot wipe-super super_empty.img
fastboot set_active b
fastboot wipe-super super_empty.img
fastboot set_active a

5.2 刷入镜像

下载 PixelExperience

重启到 recovery，在 recovery 中 Apply Update 选择 Apply from ADB，刷入

adb sideload filename.zip
